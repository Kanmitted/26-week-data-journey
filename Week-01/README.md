# Week 1 — Excel Foundations and KPI Dashboard

## Weekly Goal

Set up the tools for the 26-week learning journey, refresh core Excel skills, practise Power Query, and publish a one-page KPI dashboard using the Online Retail II dataset.

## How to Follow This Week

Use the **Daily Lessons** sheet in the tracker as your step-by-step lesson list. Start with the row marked **NEXT**, open its link, complete that one task, and mark it Done before moving on. Optional lessons are marked separately. Each lesson has its own task and completion check.

## Schedule and Learning Path

### Monday — Set up and refresh Excel (6 hours)

- Set up GitHub, create the `26-week-data-journey` repository, and prepare Kaggle and LinkedIn.
- Download Alex The Analyst's Excel practice files and the Online Retail II dataset.
- Learn and practise Excel formulas, data cleaning, XLOOKUP, Pivot Tables, conditional formatting, and charts.
- Begin the Power Query course: lessons 1–3.

**Evidence:** Notes and an Excel practice file.

### Wednesday — Practise Power Query (2 hours)

- Continue with Power Query lessons 4–11, covering data imports, appending, and merging.
- Load the Online Retail II data and practise merging it with a Region table.

**Evidence:** Completed Power Query exercises.

### Thursday — Apply Power Query to real data (2 hours)

- Follow lessons 16–24, practising splitting, filtering, replacing, grouping, and unpivoting data.
- Complete three separate cleaning tasks on the Online Retail II data.

**Evidence:** A cleaned and applied work file.

### Saturday — Build and publish (6 hours)

- Continue with the scheduled Power Query lessons, including creating revenue, year, and month fields and refreshing queries.
- Follow Alex The Analyst's full Excel project as a guide.
- Build a dashboard with four KPI values, a monthly revenue line chart, a top 10 countries bar chart, and a country slicer.
- Upload the workbook to GitHub, add this week's project details and a screenshot to the README, publish a LinkedIn post, and complete the Weekly Review tab.

**Deliverable:** Excel KPI dashboard v1 published on GitHub.

## Dashboard KPIs

1. **Total revenue**
2. **Number of orders** (distinct invoices)
3. **Average order value (AOV)** — revenue divided by orders
4. **Repeat-customer rate** — customers with two or more invoices divided by all customers
